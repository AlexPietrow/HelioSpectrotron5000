Help

HelioSpectrotron 5000 is an interactive solar spectral atlas that lets you inspect reference spectra, apply optional spectral-resolution degradation, and overlay telluric transmission for typical observing altitudes.

Black line represents the solar spectrum, the red line represents the telluric spectrum Tip: press Enter in any input to re-render Hover the plot to read wavelength + intensity Use “CSV” to copy wavelength + intensity Press “Dark” for dark mode
Quick start
  1. Pick a diagnostic via Jump to, or type a Central wavelength and hit Go.
  2. Adjust Window Size to set how much spectrum you see.
  3. Use Resolution (20k–200k) to emulate your instrument; choose ∞ for the raw atlas.
  4. Toggle Tellurics and select Altitude to match observing conditions.
  5. Export with PNG or copy data via CSV.
Controls explained
  • Central wavelength: recenters the displayed window.
  • Window Size: total width of the displayed interval.
  • Window Step: shifts the window left/right by the chosen step size.
  • Labels: toggles curated line identifications in the plot.
  • Legend: toggles legend (solar/tellurics/overlays).
  • 1D/2D: toggles 1D and 2D spectra in plot.
  • Å/nm: display unit toggle (does not change internal sampling).
  • Light/Dark: theme toggle.
Resolution (R@500nm) and REF∞

The reference atlas is treated as effectively “infinite resolution”. Choosing a finite resolving power applies spectral broadening to emulate an instrument.

  • ∞: no degradation.
  • 20k–200k: approximate instrumental broadening.
  • REF∞: overlays the undegraded reference for direct comparison.
Tellurics, altitude, and Air/Vacuum
  • Tellurics On/Off: toggles atmospheric transmission overlay.
  • Altitude: changes expected telluric absorption strength.
  • Air/Vacuum: selects wavelength convention used for display and backend queries.
Flux modes and export
  • Normalized: continuum-normalized intensity.
  • Fν / Fλ: absolute units (as provided by the backend).
  • PNG: downloads the currently displayed plot.
  • CSV: opens a modal with wavelength + y values (TSV) for copy/paste.
Common pitfalls
  • If the plot looks “empty”, increase Window Size or verify you’re within the atlas wavelength range.
  • If line centers look shifted, confirm Air/Vacuum matches your line list or observation.
  • Only a subsection of spectral lines are labeled to avoid overcrowding, and only 60 lines are printed per window. Please refer to the source book, or OCR table on the project Github for a full list.
  • While taken at high altitude, this atlas still contains telluric features that cannot be removed. Red lines overlapping with black lines are how tellurics are identified.

Data and external resources

  • Solar reference atlas: Neckel & Labs (1984) via ISPy
  • Telluric transmission: TAPAS atmospheric transmission service (Bertaux et al. 2014)
  • Line identifications: Moore et al. (1966) and Babcock & Moore (1947)
  • Air–vacuum wavelength conversion: Greisen et al. (2006)
